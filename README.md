# Foreign-Exchange-FX-Banking-Gateway
FX Banking Gateway — высокопроизводительный FinTech-шлюз на Go (Clean Architecture) для обработки и логирования валютных транзакций. Реализует фиксированную точность вычислений (int64), кэширующий декоратор для Redis, динамический расчет волатильных спредов и Graceful Shutdown.
